# Íris Roadmap

Íris is a fork of OpenScreen with a different intent — a lighter, more stable, more polished screen recorder for macOS, Windows and Linux — not a continuation of OpenScreen's own roadmap. The AI Edition direction, GitHub issue backlog, and Discord-based process from the previous roadmap belonged to OpenScreen's own plans and don't carry over here.

This document is a placeholder. Íris's own roadmap will be written here as priorities get defined.

## North star

**Record → Edit → Export**, on all three platforms, with three priorities over everything else:

- **Performance** — lower idle and recording-time resource usage, faster launch, smaller install.
- **Stability** — a hardened capture and export pipeline.
- **Interface polish** — the visual system documented in [`DESIGN.md`](./DESIGN.md).

See [`README.md`](./README.md#why-this-fork-exists) for the full rationale.
