## Export (`npm run bench:export`)

`bench:export` triggers an MP4 export through the maximized editor window.
Five attempts were made in this session; all five failed with a Playwright
click timeout on `testId-export-panel-button`, intercepted by the editor's
footer bar (`<div class="flex-shrink-0 p-3 border-t ... bg-black/25">`). This
is the known, pre-existing UI bug (footer overlaps the sidebar export button
in the maximized editor), already logged in the project's SDD ledger as a
product bug out of scope for Phase 0. It reproduces at roughly the previously
reported ~24-out-of-25 failure rate — 5/5 failures in this session is
consistent with that, not a new regression.

No fresh measurement was obtained. The frozen budget below reuses the last
known-good measurement from a prior task:
